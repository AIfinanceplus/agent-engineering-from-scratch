AGENT ENGINEERING FROM SCRATCH · V5

Policy Engine：有能力，不等于有权限

Tool Object 描述 capability：schema、function、retry、risk。Policy Engine 则独立决定当前请求是否允许执行。 即使 Tool 存在、参数完全合法，也可能得到 ALLOW、REQUIRE_APPROVAL 或 DENY。

V5 核心原则 Capability ≠ Permission Policy before Execution
