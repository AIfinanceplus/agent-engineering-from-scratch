AGENT ENGINEERING FROM SCRATCH · V3

Retry 与 Loop Detection：同一个动作，谁在重复？

V3 把两种“重复”彻底分开：Tool 因 Timeout 临时失败时，Runtime 可以在同一个 step 内重试； 如果 Model 在看到 Observation 后又提出完全相同的 Tool Call，则由 Duplicate Detector 阻止第二次真实执行。

V3 核心原则 Retry = Runtime 重复执行 Loop = Model 重复决策
