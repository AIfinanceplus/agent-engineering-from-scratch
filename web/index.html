Runtime Guard：模型也必须被约束

V1 保护 Tool 边界；V2 再向上保护 Model 边界。Runtime 会先验证 Model Response， 再用 MAX_STEPS 限制 Tool Call 次数。即使每次 Tool Call 都合法，模型也不能无限循环。

V2 核心原则 Model 可以犯错 Runtime 必须有硬边界
