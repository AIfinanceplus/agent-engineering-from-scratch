# 本课：Paper Portfolio Risk

目标：把多份 **追加式纸面成交账本** 重放成组合投影，并在任何风险增加前做原子预检。

本课不连接交易所、不使用凭据，也不会创建真实订单。

## 关键边界

| 概念 | 正确含义 |
| --- | --- |
| 单笔账本 | 每一笔纸面交易的不可变事实来源；报价不是成交。 |
| 组合投影 | 从所有已重放的未结算账本聚合出来的只读状态。 |
| 原子预检 | 在投影状态检查限额，尚未写入账本、尚未产生成交。 |
| 限额拦截 | `effect_count: 0`；被拒绝的命令不会增加事件数、数量或成本。 |

## 演示轨迹

1. A 的 Kalshi 腿成交 4，组合裸腿风险为 4，正好占满限额。
2. B 想新增 1；投影风险将变为 5，大于 `max_total_leg_risk_quantity=4`，因此被阻断。
3. A 的 Polymarket 对冲腿成交 4，A 被完全匹配，组合风险容量释放。
4. 再预检 B 的 1；此时通过，随后才追加 `paper_fill_recorded`。

所以，**预检通过不等于成交，账本追加才等于纸面成交**。组合快照也是投影：它可以随时从每笔 JSONL 事件重放出来，不能取代原始事件。

## 运行

在控制台选择 `本课：Paper Portfolio Risk`，点击运行。Live Stream 的每条帧会先写入运行事件日志；每个成交事件也会先由纸面账本持久化，再显示在页面。
